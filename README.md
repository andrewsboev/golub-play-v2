# Голубь v2

[Открыть страницу прогресса](https://andrewsboev.github.io/golub-play-v2/)

Перенос Golub / PiGine с Pascal на WebAssembly. Пока здесь промежуточные снимки Windows и результаты проверок; игровая Wasm-сборка ещё не готова. Исходники разрабатываются отдельно; этот репозиторий содержит публичные артефакты.

[Первая версия игры](https://andrewsboev.github.io/golub-play/) сохранена по прежнему адресу. Каталоги `progress/` неизменяемые; новые публикации сохраняют прежние снимки.
